# Krishna Restaurant

A simple and responsive **restaurant website** built using **HTML5 and CSS3**.
This project was created as part of my web development practice to improve my understanding of webpage structure, navigation, content organization, and CSS styling.

## 📌 Project Overview

**Krishna Restaurant** is a practice restaurant website designed to present a simple online presence for a restaurant.

The website provides information about the restaurant, its food menu, opening hours, and contact details through a clean and easy-to-navigate layout.

## 🌐 Website Sections

The website includes the following sections:

* **Home** – Welcome section with the restaurant introduction
* **About** – Information about Krishna Restaurant
* **Menu** – Food items and available dishes
* **Opening Hours** – Restaurant operating hours
* **Contact** – Contact information

## 🚀 How to Run the Project

### Method 1 — Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your default browser.

### Method 2 — Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Run the file using a browser or Live Server.
4. The Krishna Restaurant website will open in your browser.
